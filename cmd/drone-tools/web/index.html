Flight Workspace

Load GPX, PX4 ULog, ArduPilot DataFlash, MAVLink TLOG, KML or GeoJSON to render a flight locally. GPX, ULog, DataFlash and TLOG also get Flight Analysis and local telemetry charts. ULog, DataFlash and TLOG additionally get deterministic Flight Health scoring, including radio/link health when MAVLink RADIO_STATUS telemetry is available.

Select a supported flight file. No map tiles, CDN or external service is contacted.
